# 0.2.0 preparation checks

Checked locally on Linux on November 23, 2026. Status: prepared, unpublished.

## Review scope and findings

Reviewed the six feature and fix commits from tag `0.1.2` through `9a0f5b4`, with their source changes, tests, and recorded runtime evidence. The following checks concern the local release preparation.

- The packaged-client verifier retained a checksum from before the draft-editor client. Running it against the staged client failed with `Wrong client manifest.`. Updating its pinned manifest hash makes all 35 client entries pass.
- Release notes and implementation status still described a Linux-only patched-server 0.1.0 candidate. Current docs describe the standard-server architecture, 0.2.0 features, upgrade steps, and verification limits.
- Component URLs referenced unpublished development tags. Both archives now target `components-0.2.0`. These URLs require publication before user downloads can work.

- `git diff --check`: passed.
- `node scripts/verify-candidate.mjs dist/0.2.0`: passed for the staged plugin files and release notes.
